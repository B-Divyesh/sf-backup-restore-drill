How it works

Check one selected backup file

Use a small check on a schedule. Keep full recovery practice for a separate exercise.

  1. 01

    Create a temporary restore folder

    Restore Drill creates a new folder for each check.

  2. 02

    Restore selected files

    Configure your backup command to restore only the files you want to check.

  3. 03

    Compare the restored file

    Compare its SHA-256 fingerprint. It can check whether an application opens the restored file.

  4. 04

    Write a receipt

    The receipt is hash-linked JSON. A later change is detected when the chain is checked.

Setup

Start with one important file

Choose a file you would notice missing. Save its SHA-256 fingerprint from a trusted copy.

  • ✓Rejects links and files outside the temporary restore folder.
  • !Restore Drill checks your selected files. Your backup command controls its own restore scope.
restore-drill.toml
version = 1
name = "monthly essentials"
cadence_days = 30
receipt_dir = ".restore-drill/receipts"

[restore]
command = ["restic", "restore", "latest", "--target", "{target}", "--include", "/Documents/tax.pdf"]

[[sample]]
path = "Documents/tax.pdf"
sha256 = "your-known-good-sha256"

Next: restore-drill check && restore-drill run
